    ⚙️ Setup — 3 steps, done in 2 minutes

    No Vapi signup. No API keys. No separate accounts. Calling is built in and invisible.

      📏 Call rules

      • 📞 Calls or texts only — never app notifications. Notifications get missed; a call doesn't.
      • ⏱️ Short calls — the plan in under a minute, then done.
      • ⭐ Important matters only — appointments, deadlines, bills, nearby errands. No noise.
      • 🤫 Never while you're already chatting with Echo.
      • 🛑 You can pause calls any time from this screen.

      💵 Pricing

      $2.99/month — calls included. Or bring your own Vapi account instead (new Vapi signups get $10 free credit, roughly 150–200 minutes). Name, list home, and pricing are still open decisions — this build uses these defaults and they can change.

      🔑 Calling settings

      SideTrip calls through Vapi (voice AI). Your key is stored only on this device — it is never sent to the repo or anyone else. Leave the key blank to stay in dry-run mode: the app builds the exact call request and shows it, without sending a real call.

      Default is Brooke, the family voice assistant.

      🖥️ The server-side watcher

      True background watching + calling can't run inside this web app (iOS suspends web apps; Android throttles them). The watcher runs server-side — the SideTrip MCP server / hosted service — and this app is its dashboard. The trigger engine in app.js (evaluateTriggers / buildPlan / placeCall) is the same logic the server runs.
